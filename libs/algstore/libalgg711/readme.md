## G711编解码

### 1.1. 算法类型

音频

### 1.2. 算法描述

G711编解码是把采样数据转为G711码流或是把G711码流转换为采样数据。

### **1.3.** API参考

- `TS_ALG_G711_Encoder`：G711编码算法。
- `TS_ALG_G711_Decoder`：G711解码算法。
- `TS_ALG_G711_Transcode`：G711码流格式转换算法。

#### `TS_ALG_G711_Encoder`

**[描述]**

G711编码算法。

**[语法]**

`TS_S32 TS_ALG_G711_Encoder(TS_S32 mode, TS_U8 *pOut, const TS_U8 *pSrc, TS_S32 s32InSize);`

**[参数]**

| 参数名称  |       描述       | 输入/输出 |
| :-------: | :--------------: | :-------: |
|   mode    |     编码模式     |   输入    |
|   pOut    |   输出码流格式   |   输出    |
|   pSrc    | 输入采样数据地址 |   输入    |
| s32InSize | 输入采样数据个数 |   输入    |

**[返回值]**

| 返回值 |       描述       |
| :----: | :--------------: |
| 字节数 | 输出编码的字节数 |



#### `TS_ALG_G711_Decoder`

**[描述]**

G711解码算法。

**[语法]**

`TS_S32 TS_ALG_G711_Decoder(TS_S32 mode, TS_U8 *pOut, const TS_U8 *pSrc, TS_S32 s32InSize);`

**[参数]**

| 参数名称  |       描述       | 输入/输出 |
| :-------: | :--------------: | :-------: |
|   mode    |     解码模式     |   输入    |
|   pOut    | 输出采样数据地址 |   输出    |
|   pSrc    |   输入码流地址   |   输入    |
| s32InSize |  输入码流字节数  |   输入    |

**[返回值]**

| 返回值 |        描述        |
| :----: | :----------------: |
| 字节数 | 解码采样点的字节数 |



#### `TS_ALG_G711_Transcode`

**[描述]**

G711码流模式转换。

**[语法]**

`TS_S32 TS_ALG_G711_Transcode(TS_S32 mode, TS_U8 *pOut, const TS_U8 *pSrc, TS_S32 s32InSize);`

**[参数]**

| 参数名称  |      描述      | 输入/输出 |
| :-------: | :------------: | :-------: |
|   mode    |  输入码流模式  |   输入    |
|   pOut    |  输出码流地址  |   输出    |
|   pSrc    |  输入码流地址  |   输入    |
| s32InSize | 输入码流字节数 |   输入    |

**[返回值]**

| 返回值 |     描述     |
| :----: | :----------: |
| 字节数 | 转码的字节数 |
